FIX 3 — My Videos: only show actually posted videos
═══════════════════════════════════════
My Videos should ONLY show videos that were successfully 
posted to Instagram or Facebook via Metricool.

A video is "posted" if:
  status = 'done' AND metricool_post_id IS NOT NULL

Remove ALL other videos from the default view:
  - No "Generated" tab
  - No failed videos
  - No videos without metricool_post_id
  - No videos that only have fal_image_url

Query:
  SELECT v.*, 
    COALESCE(v.captioned_url, v.cloudinary_url, v.fal_image_url) as thumbnail_url
  FROM videos v
  WHERE v.user_id = auth.uid()
  AND v.status = 'done'
  AND v.metricool_post_id IS NOT NULL
  ORDER BY v.created_at DESC

For thumbnails: since these are posted videos, pull the 
actual thumbnail from Metricool reels data matching by 
metricool_post_id:
  For each video, look up the matching reel in Metricool
  Use reel.imageUrl as the thumbnail
  Fallback to video.fal_image_url or gradient

  - Real thumbnail from Metricool
  - Hook text (video.script_prompt first 40 chars)

  - Real metrics from Metricool: views, likes, engagement

Empty state if no posted videos:
